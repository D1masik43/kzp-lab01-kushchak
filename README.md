# Спортивна ліга — консольний звіт

Лабораторна робота № 1 з курсу «Кросплатформні засоби програмування».
Варіант 17.

## Призначення

Програма читає записи результатів матчів з `data/input.csv`, перевіряє їх,
обчислює показники ліги та формує звіт у консоль і текстовий файл.

## Формат входу

Один запис розміщують у рядку, поля розділяють крапкою з комою (`;`).
Файл кодують у UTF-8. Формат запису:

```
home;away;homeScore;awayScore;attendance
```

| Поле        | Тип    | Опис                          |
|-------------|--------|-------------------------------|
| home        | String | назва команди господарів      |
| away        | String | назва команди гостей          |
| homeScore   | int    | голи господарів                |
| awayScore   | int    | голи гостей                    |
| attendance  | int    | кількість глядачів на матчі    |

Приклад:

```
Динамо;Шахтар;2;1;18500
```

## Показники звіту

1. Кількість коректних записів.
2. Середня кількість голів за матч.
3. Найбільша відвідуваність.
4. Сумарна відвідуваність.

## Збірка та запуск

```text
mvnw.cmd verify
mvnw.cmd package
java -jar target/lab01-1.0.0.jar
```

На macOS та Ubuntu замість `mvnw.cmd` використовуйте `./mvnw`.

### Аргументи командного рядка

```text
java -jar target/lab01-1.0.0.jar [--help] [--version] [--input <файл>] [--output <файл>]
```

- `--help` — вивести довідку та завершити роботу;
- `--version` — вивести версію програми;
- `--input <файл>` — шлях до вхідного CSV (типово `data/input.csv`);
- `--output <файл>` — шлях до файла звіту (типово `out/report.txt`).
